# 即梦批量生成控制台

面向 AI 短剧 / 分镜视频生产的**前后端完整项目**：前端是分镜批量管理工作台，后端是本地桥接服务，通过即梦官方**创作 CLI（`dreamina`）**完成真实视频生成。**无任何演示/模拟数据**——所有数据来自真实数据流。

> ⚠ 2026-09-18：**画布 CLI（`dreamina-canvas`）已彻底移除**，本项目只使用创作 CLI 一个生成引擎；历史上曾依赖画布 CLI 的能力（画布节点引用、报价→确认的积分安全阀）随之下线，积分改为"提交前余额提醒"（`creditWarnBelow`）。

## 快速开始

```bash
cd jimeng-console
node server/index.js          # 1. 启动后端（唯一启动步骤，零依赖无需安装）
```

2. 浏览器打开 **http://127.0.0.1:8787/** —— 前端由后端托管，同源直连 `/api/v1`。
3. 页面初始为空态（还没有分镜）——点「批量导入提示词」，粘贴多段提示词（`;;` 分隔）即可创建真实分镜。

其它打开方式：

```bash
node build.js                              # 重建发布版（改完 app/ 后必须执行）
dist/即梦批量生成控制台.html                # 双击单文件版，自动连接 127.0.0.1:8787
```

## 前后端如何联通

- 前端所有数据来自 `app/api.js` 发出的真实 HTTP 请求，**没有 mock 模式**。
- `baseUrl` 自动选择：由后端托管时取同源 `/api/v1`；以 `file://` 打开发布版时取 `http://127.0.0.1:8787/api/v1`（后端 CORS 已放行）。
- 需要改配置时，在 `index.html` 引入脚本**之前**插入：

```html
<script>
  window.APP_CONFIG = { baseUrl: '...', token: '<用户 token>', projectId: 'pj_1' };
</script>
```

> 发布版是构建产物：改完 `app/` 需 `node build.js` 重建。

## 真实生成链路

1. 导入 / 新建分镜（`queued`）→ 勾选后「提交所选」（`batch-submit`，提交前确认创作 CLI 可用，未连接返回 `51001`）；
2. 后端队列按并发数派发 worker：**派发前先把任务落库**，再由创作 CLI 适配层组装并执行 `dreamina text2video` / `multimodal2video`；
3. 任务在即梦侧为异步：拿到 `submit_id` 后轮询 `query_result` 至 `gen_status` 终态；`fail` 映射为 `51002`、审核拒绝 → `51003`；
4. 完成：产物下载校验后由 `/files/` 提供 `videoUrl`；本地跟踪中断（重启）时由启动清理把分镜标为失败并保留 `submit_id` 供续查；
5. 前端 3–10s 退避轮询 `GET /storyboards/progress`（只回有变化的行）。

> **账号要求**：真实生成需要已开通相应权限的即梦账号（实测非会员账号会被服务端闸门拒绝，任务以 `40300` 给出明确原因；接口联通、错误处理、恢复协议均已按真实链路落地）。

## 前端核心机制

- **轮询退避**：基线 3s，连续 3 次无变化 → 6s → 10s 封顶；异常指数退避封顶 30s；页面隐藏暂停、恢复即拉；全部终态停止。
- **乐观更新 + 回滚**：改时长立即生效（300ms 合并提交），失败回滚 + Toast；批量提交 `accepted[]` 乐观置队。
- **四态齐全**：骨架屏 / 空态（含「批量导入」引导）/ 错误态（带重试）/ 降级。
- **枚举不硬编码**：模型 / 画幅 / 分辨率 / 时长边界全部来自 `GET /meta/options`（后端合并静态配置与 CLI 实时模型目录）。
- **时长控件**：步进器、双击直接输入、预设下拉；已完成分镜由服务端 `canEditDuration` 锁定。

## 构建发布版

```bash
node build.js
```

脚本内联四个文件、写出 `dist/即梦批量生成控制台.html`，并自动校验产物（`$$` 是否被吞、script/style 块数量、有无残留外部引用），任一不通过即报错退出。

> ⚠️ 改构建流程时务必保留两道防护：`String.replace` 必须用回调形式（字符串形式会吞 `$$`）；内联前必须检查字面量 `</script`。

## 推送到 Git 仓库

```bash
export GITHUB_TOKEN=ghp_你的令牌      # 命令前带空格，避免进入 shell 历史
bash scripts/push-to-github.sh
```

一条命令完成：校验令牌 → 创建**私有**仓库 → 推送 → 回查私密性。令牌不会写进 `.git/config`。详见 [`docs/Git 私密仓库操作指南.md`](docs/Git%20%E7%A7%81%E5%AF%86%E4%BB%93%E5%BA%93%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97.md)。

## 已知边界

1. 素材库当前无新增入口（上传接口随占位功能移除）；素材存在时绑定 / 解绑功能完整可用。
2. 真实生成的 CLI flag 在运行时由 `model list` 实时规格解析（禁止硬编码未验证 flag）。
3. 取消运行中任务只能停止本地跟踪（CLI 无取消命令），即梦侧照常计费。
4. `prompt()` / `confirm()` 为浏览器原生弹窗，正式实现应换设计系统弹层。
